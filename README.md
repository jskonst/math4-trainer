# Тренажёр по математике, 4 класс

Фронтенд-тренажёр по тетради И. Е. Андреевой «Математика. Тетрадь-тренажёр, 4 класс». Можно выбрать раздел и подраздел, решить задания, нажать «Проверить» и при ошибке — «Показать ответ». Счётчик верных и неверных ответов хранится в браузере.

Рабочая копия: [https://jskonst.github.io/math4-trainer/](https://jskonst.github.io/math4-trainer/)

## Как запустить локально

```bash
npm ci
npm test
npm run dev
```

Сборка и просмотр той же версии, что уйдёт на GitHub Pages:

```bash
npm run build
npm run preview
```

В CI (GitHub Actions) на каждый push и pull request выполняются `npm ci`, lint, тесты и сборка. При push в `main` сайт выкладывается на GitHub Pages.

## Как устроены задания

Каталог лежит в `src/data/tasks.json`. У каждого задания есть:

- `id`, `section_id`, `subsection_id`, `book_page`, `number`, `type`, `prompt`
- `answer_entry` — как вводить ответ: число, величина, знак `>`, `<`, `=`, выбор, список и другие типы из тетради
- `items[]` — пункты задания с полем `answer` (и при необходимости `acceptable`, `unit`)
- `manual` — показать задание и пояснение, но не проверять автоматически (рисунки, теория)

Проверка живёт в `src/lib/check.ts`. Она понимает эквивалентные записи величин (например, `15 мин` и `1/4 ч`) и варианты из `acceptable`. Счётчик — в `src/lib/score.ts`: задание засчитывается один раз по первой проверке; кнопка «Показать ответ» отмечает его как неверное.

## Как добавить задание

1. Откройте `src/data/tasks.json` и добавьте объект в массив `tasks` (раздел должен быть в `sections`).
2. Для автопроверки укажите `manual: false` и ответы в `answer` или в `items[].answer`.
3. Если правильных формулировок несколько, перечислите их в `acceptable`.
4. Запустите `npm test` — в том числе проверку, что официальный ответ каждого автопроверяемого задания проходит через тот же проверяющий код.
